# 🚗 MS Cars - Luxury Car Collection Website

A modern luxury car collection website built using HTML, CSS, and JavaScript.

## 🌟 About the Project

MS Cars is a front-end web development project designed to showcase a luxury car collection through a stylish and user-friendly website.

## ✨ Features

- Modern and clean website design
- Luxury car collection showcase
- Dedicated About page
- Contact page
- Easy navigation between pages
- Custom favicon

## 🛠️ Technologies Used

- **HTML5** - Website structure
- **CSS3** - Styling and layout
- **JavaScript** - Website functionality

## 📂 Project Structure

```text
Ms-cars/
├── index.html
├── about.html
├── contact.html
├── style.css
├── script.js
├── favicon.ico
└── README.md
```

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the MS Cars website.
